# **App Name**: PartyFlow

## Core Features:

- User Authentication & Age Verification: Secure user registration (Google/Apple/OTP) and mandatory age verification screen before catalog access, ensuring compliance for liquor sales.
- Product Discovery Tool (AI-powered): An AI tool that suggests curated liquor selections and combos based on user-selected 'moods' or occasions (e.g., 'Pre-copeo', 'Cena Romántica') to enhance browsing.
- Interactive Cart & Speedy Checkout: An interactive shopping cart where users can add/remove items and proceed through a streamlined, multi-option checkout, including secure stored payment methods and local payment links.
- Real-time Order & Delivery Tracking: Customers can track their order status and see the delivery driver's live location on an interactive map, enabled by real-time updates (e.g., WebSockets).
- Admin Dashboard: Inventory & Order Management: A centralized dashboard for administrators to monitor inventory levels in real-time, view incoming orders, and manage basic product availability.
- Driver Interface & Route Optimization: A mobile-responsive interface for delivery drivers to manage availability, receive new order notifications with alerts, and access integrated maps for optimal routing.
- Warehouse Dispatch System: An optimized screen for warehouse staff to view incoming orders, use an interactive packing checklist to ensure accuracy, and mark orders as 'ready for pickup'.

## Style Guidelines:

- Background color: Deep Night Black / Very Dark Space Blue (#0D0E15), establishing a predominant dark mode theme for the nightlife aesthetic.
- Primary color: Electric Magenta (#FF007A), serving as the main action color for buttons and interactive elements, conveying energy and a party vibe.
- Accent color 1: Neon Cyan / Turquoise (#00F5D4), used to highlight interactive elements, success states, and give a fresh, dynamic feel.
- Accent color 2: Amber Yellow/Gold (#FFB703), reserved for alerts, urgent messages, or to emphasize premium products and special offers.
- Headline and body font: 'Poppins' (sans-serif) for its precise, contemporary, and avant-garde aesthetic, perfectly fitting the vibrant and premium app persona.
- Minimalist iconography featuring elegant glyphs with a neon glow effect, aligning with the modern dark mode and nightlife visual theme.
- A fluid and interactive layout prioritizing a quick purchasing flow (less than 3 clicks), prominent call-to-action elements, and an overall intuitive user experience.
- Smooth and engaging animations and transitions to enhance the 'instant party delivery' experience, making interactions feel responsive and dynamic.
